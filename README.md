## 📝 Writeup Format

Each lab writeup follows a consistent structure:

### 1. Lab Information

* **Lab:** Lab name
* **Category:** Vulnerability category
* **Difficulty:** Apprentice / Practitioner / Expert
* **Objective:** What needs to be achieved

### 2. Vulnerability

Explanation of the vulnerability and why it exists.

### 3. Methodology

Step-by-step explanation of how the vulnerability was identified and exploited.

### 4. Burp Suite Analysis

Relevant requests, responses, parameters, headers, and Burp Suite techniques used during the lab.

### 5. Exploitation

The payload or attack technique used to successfully exploit the vulnerability.

### 6. Solution

The final steps required to solve the lab.

### 7. Key Takeaways

Important concepts and lessons learned from the lab.
